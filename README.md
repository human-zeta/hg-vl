# hg-vl

**68 herramientas de navegador para gente que hace visuales.** Shaders, video,
audio, color, tipografía, streaming, producción y show en vivo. Todas gratis,
sin registro, sin instalar nada, y casi todas corriendo enteras en tu máquina.

Vivo en **[hg-vl.com](https://hg-vl.com)** · el índice del laboratorio está en
**[hg-vl.com/labs/](https://hg-vl.com/labs/)**

Human Glitche es un estudio de una persona en La Plata, Argentina. Estas son las
herramientas que fui necesitando para trabajar y terminé abriendo.

## Correrlo local

No hay build. Son páginas HTML estáticas: un servidor de archivos alcanza.

```bash
git clone https://github.com/human-zeta/hg-vl.git
cd hg-vl
python3 -m http.server 8000
```

Después abrí `http://localhost:8000/labs/` para el índice, o cualquier
herramienta por su ruta (`/forge/`, `/isf/`, `/lut/`…).

Cada herramienta es autocontenida: vive en su carpeta, no importa nada de las
otras y podés copiártela suelta. Las dependencias entran por CDN (`esm.sh`,
`cdn.jsdelivr.net`) — no hay `node_modules` ni paso de compilación.

## Cómo está hecho

HTML, CSS y JavaScript a mano. WebGL para los shaders, WebAudio para el
análisis de audio, WebCodecs para grabar video, ONNX/transformers.js para los
modelos que corren en el navegador (recorte de sujeto, profundidad, separación
de stems). Sin framework y sin backend: salvo las que dicen lo contrario, las
herramientas no mandan tus archivos a ningún lado porque no hay a dónde
mandarlos.

**Hallazgos que quedaron en el código**, por si le ahorran tiempo a alguien:

- **Un uber-shader se paga al peor caso.** Con N familias de patrón detrás de un
  `if/else` sobre un uniform, el compilador emite las N ramas y asigna registros
  por la más cara: la familia barata corre con la huella de la carísima. En GPUs
  integradas de Windows eso dispara el TDR y congela el navegador. Se arregla
  inyectando la familia como `const float` en vez de uniform: el `if/else` se
  pliega y las otras ramas mueren como código muerto.
- **El renderer de ISF sí soporta INPUTS `long`**, así que un `.fs` exportado
  puede exponer dropdowns con etiquetas dentro de VDMX. No está documentado;
  está verificado con pixel-test.
- **`startTime` calculado desde `Date.now()`** da control determinista de `TIME`
  (con `performance.now()` da 0 por precisión de float32). Eso es lo que permite
  renderear loops de fase perfecta offline.
- **El host ISF no tiene PASSES persistentes**, así que los trails de feedback
  hay que hacerlos fuera del shader, componiendo en un canvas 2D.
